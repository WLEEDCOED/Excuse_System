# University Excuse Management System

A PHP/MySQL system for managing university excuse requests.

## Project Structure

```text
university-excuse-management-system/
├── README.md
├── docs/
│   └── screenshots/
├── src/
│   ├── pages/
│   ├── includes/
│   ├── assets/
│   │   └── images/
│   ├── css/
│   ├── js/
│   └── php/
├── uploads/
└── database/
    └── schema.sql
```

## Local Entry Point

Open `index.php` from the project root. It redirects to `src/pages/index.php`.
